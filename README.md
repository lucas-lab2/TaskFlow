# TaskFlow — Collaborative Task & Project Management

A modern, full-stack web application for managing tasks, projects, and team collaboration. Built with Next.js, TypeScript, and Tailwind CSS.

## 🚀 Project Overview

**TaskFlow** is a collaborative task and project management application designed to help teams organize, track, and complete their work efficiently. The application provides an intuitive interface for creating projects, managing tasks with priorities and deadlines, and collaborating with team members in real time.

### Key Features (Planned)
- **User Authentication** — Secure login and registration
- **Project Management** — Create and organize projects with descriptions and deadlines
- **Task Boards** — Kanban-style boards for visual task tracking
- **Task Management** — Create, assign, prioritize, and track tasks
- **Dashboard** — Overview of projects, tasks, and activity
- **Team Collaboration** — Assign tasks to team members
- **Search & Filter** — Find tasks and projects quickly
- **Responsive Design** — Works seamlessly on desktop and mobile

## 🏁 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/lucas-lab2/TaskFlow.git)](https://github.com/lucas-lab2/TaskFlow.git

# Navigate to the project
cd taskflow

# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.
