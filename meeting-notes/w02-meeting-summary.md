## 1. Project Discussion

### Purpose
Build a collaborative **Task & Project Management** web application called **TaskFlow** using a full-stack technology approach. The application will allow users to create projects, manage tasks with priorities and deadlines, and collaborate with team members.

### Requirements
- Full-stack web application using Next.js
- User authentication (login/registration)
- CRUD operations for projects and tasks
- Responsive, modern UI design
- Cloud deployment
- Collaborative development using GitHub

### Limitations
- Must be completed within the course timeline (~5 weeks of development)
- Team size constraints
- Must use web technologies covered in WDD 430
- Free-tier hosting and database services

## 3. Design Theme Decisions

The group agreed on a **modern, professional design** with:
- **Primary Color**: Deep Indigo (`#4F46E5`) — conveys trust and productivity
- **Secondary Color**: Teal/Cyan (`#06B6D4`) — freshness and clarity
- **Accent Color**: Amber (`#F59E0B`) — draws attention to deadlines and priorities
- **Typography**: Inter font family via Google Fonts
- **Layout**: Sidebar navigation with main content area
- **Design Style**: Clean, minimal with subtle shadows and rounded corners

Full design documentation: See [design-system.md](../design/design-system.md)
